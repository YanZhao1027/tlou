# 下一阶段经验检验协议（拟登记，尚非已完成预注册）

本协议将当前探索性模拟与未来经验研究分开。当前网格和结果已经观察过，不追称预注册研究。

## 1. 先固定研究对象

首项经验研究选择一个地区、清楚年龄范围和家庭结构；同时保留总人口基准以检查选择偏差。单位必须明确是个人、家户还是消费单位。现金工资、经营收入、转移、资本和住房估算服务分开。

## 2. 三项待检验而非恒真的命题

H1：在特定时间窗内，自动化暴露提高的家庭，其净劳动现金收入损失可能超过该户实际得到的消费价格节约。拒绝方向：工资互补／岗位重建收益或降价节约足以抵消，或估计无法排除零。

H2：在控制基准资源和债务后，收入下降与既有大额付款更早重叠的家庭，可能面临更高的未融资缺口风险。必须测量实际融资、延期、家族支持及消费调整，不能把固定计划失败当成真实违约。

H3：在相同任务暴露下，预先存在的资本权益或社会保障渠道，可能改变冲击传导。必须区分政策保护、资产选择与未观测能力，不能只做持股／不持股的表面均值比较。

## 3. 数据契约

每个变量记录定义、统计总体、单位、价格年、观察年、均值或中位数、来源表号、处理脚本、缺失规则。政策记录生效日期、资格、费率、上下限、个人和雇主分担及给付方式。新法规不追溯应用于旧观测，平均工资不填成代表性家庭。

原始资料许可、访问权限和再发布权限必须明确；不为通过校验而合成不存在的真实观察。

## 4. 识别与验证

采用前后比较只有在存在可信处理与对照、无重大同时混淆且前期趋势等条件合理时才具有因果解释。否则报告描述与关联。对政策规则先用权威案例逐项核对；数值应在相同舍入口径下对齐，再做家户样本回算。

预先选定留出年份或留出样本及验证指标：税后收入、福利领取资格、主要支出与现金余额分布。误差容限应根据变量测量误差和政策舍入规则确定，不能看结果后临时放宽。情景数不是样本量，不计算网格参数的社会发生概率。

## 5. 模型竞争

同时比较无自动化效应、任务互补、工资替代、就业迁移和收入恢复规格。消费既运行固定篮子也运行估计的数量响应；分别报告货币、实物服务与自主时间，不用现金作为唯一福利指标。按收入、资产、工作类型、性别、照护责任分组，但预先限制主分析数量。

## 6. 公开与质疑

公开所有主要替代规格、剔除记录、反向结果与代码版本。记录哪一项观察会改变结论；无法取得数据就保留未知。资格未知不能等于没有福利，名义余额不能等于实际购买力。

## 7. 受众伦理

尚未开展学生心理干预试验。普通读者理解访谈与未成年人临床风险研究不同；后者需要专业人员、合适伦理程序和退出／转介机制。文章不要求读者先接受末日结论，不以赞同作者作为学习效果。

## 附：把方向性语言改成可登记的经验检验

正式采集或取得微观资料后，先锁定地区、出生或年龄队列、家庭定义、暴露指标及观察窗，再将上述H1—H3具体化。例如：

- H1的主要估计量是所定义组在事先锁定窗口内，自动化相关净劳动现金变化加固定篮子价格节约后的平均差值；方向假说为小于零，而不是永远不能拒绝的“某些人可能受损”。零或正估计、置信区间及识别不足均如实报告，不能解释成理论仍然获胜。
- H2以窗口内经实际融资和转移调整后的资金缺口为结果，检验收入下降与到期付款重叠程度的边际关系；不得把研究者强迫买房造成的缺口混入真实违约样本。
- H3以冲击发生前的权益或保障资格界定分组，检验收益渠道对净现金变化的调节。先声明混淆控制和识别限制；没有随机或可信准实验，不称为因果保护效果。

观察窗（例如12或24个月）只作为待选择设计，必须在读取主要结果前锁定。不能在本轮探索性结果之后声称已经完成了上述预注册。
