# The Last of Us · 第二轮审计与发表边界报告 v1.0

日期：2026-10-17。性质：同一AI协作项目中的代码重放、独立公式复算和来源复核，不是外部第三方鉴证。

## 执行意见

可公开讨论的成果是方法论文与条件性压力测试。原12地区的未来现金流、贫困率、养老金权益和国家排名仍不得作为已验证经验结论发表。不是删除这些地区，而是将它们留在可追溯、不可静默填空的数据接入层。

## 一、本轮真正完成的工作

1. 重跑原v0.8：384案例、23,808年度、36个数值栏位。最大差1.49e-8；独立现金流加总差1.86e-9。原档案不改写。
2. 新发现并修复306条“首次缺口年龄”误标签；这个变量原来其实是最大折现资金需求时点。
3. 对TWN/IND/KEN/NGA养老金提前复利做窄修复；128条货币轨迹改变，其他256条保持原样。所有384条首次缺口标签通过回归。
4. 新建不带国家伪精度的条件实验内核：劳动与非劳动收入、成本传导、资本分配、财政增量债务与利息、名义贷款、固定预算可行性。
5. 实际运行2,268组静态网格、432组动态网格和13组命名情景。动态网格26,784年度；命名806年度，不冒充观察样本。
6. 26项自动测试通过，其中一个性质测试执行2,000组固定种子随机参数。
7. 汇总27项审计问题（原18项加新增9项）、23项来源记录及12个经验发布阻断门。
8. 形成中文方法论文候选稿、研究协议、可编辑局部Excel计算器、复现代码和更改记录。

## 二、这次新发现为何重要

### 1. 首次风险时点不是最坏时点

错误标签使读者可能误以为模型会在很晚才首次失去支付能力，实际可能早得多。修复后的字段分开报告首次失败、最低余额、最大折现融资需求。不能把一个变量解释成三个概念。

### 2. 真实统计锚点可能在转换中丢失

程序拆除旧住房预算并加上新的租金后，参考年龄预算不再等于来源预算。日本增加22.68%、台湾地区15.84%，中国假设家户22.97%。若目的是构造另一类租户，这并非禁用；但必须公布转换而不是声称“同口径实测家庭”。

### 3. 非现金收入不能偿还债务

南非原表有自有住房及免租住房的估算服务收入。把它们当现金或者纯工资，既高估可支付资源，也会错误施加劳动替代冲击。美国CE的退休缴费子项也不能由总收入乘一个固定FICA率替代。详见R06、R07。

### 4. 官方资料也要按生效日期版本化

印度2026年9月17日门槛变更的官方FAQ与仍展示旧门槛的概述网页同时存在。前者不能反推适用于全年，后者不能凭官方域名覆盖更新。南非补助金额与资产收入门槛也不应从不同更新日期拼接为完整规则。

### 5. 对上一轮审计本身的纠正

负利润不是天然不可能。原模型的问题是价格优惠被机械记作残差亏损，没有解释生产成本、收益与融资来源。新内核用独立成本块处理服务降价，但仍不等于求解全国均衡。

## 三、状态分类

- CLOSED_CODE：确定的算术和标签错误已修复，有前后对照。
- REPLACED_IN_SYNTHETIC_CORE：新内核明确改变建模边界，不声称旧国家模型被完全修好。
- OPEN_EMPIRICAL / BLOCKED：缺少匹配微观样本、政策资格、经验冲击或外部验证。
- OUT_OF_SCOPE：临床疗效、政治意图、人口命运、关系价值等不是模型可推导的对象。

## 四、尚不能解锁的经验工作

十二地区均未具备完整的同家庭样本、税费福利、住房资产、医疗和生命周期联合数据。南非补助、印度EPF/EPS、各地税率与公共服务仍不能由新通用函数替代真实制度。数据年份与政策日期统一、收入分位匹配、非正规就业和迁移样本也尚未完成。

不能以“成本下降和收入下降在程序里互相抵消”来证明真实供需、就业与资本形成达到均衡。新增外部部门是明示的模型边界，不是把未解释的钱藏到别的名字下后宣布全球财政闭合。

## 五、发表主张清单

允许：在清楚固定预算、时序和参数下推导翻转阈值；指出同终身收益不保证同流动性；公开源代码错误如何影响解释；公布经验研究需要怎样的数据才能推翻初始预期。
